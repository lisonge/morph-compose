# 桌面视觉基线

这里保留经过审阅的历史参考，不代表所有中间帧都具有理想视觉效果。

每套基线只提交：

- `manifest.txt`：案例清单与渲染参数。
- `images.json`：案例对应的公开图片链接和内容摘要，以及规范化换行后的案例清单摘要。
- `environment.txt`：渲染环境。
- `review-log.txt`：基线审阅与更新理由。

图片不再提交到仓库。对比时匿名下载到 `.cache/image/`，以附件编号命名（`<附件ID>.png`），校验摘要后复用。
下载失败、摘要不符或清单不一致都会报错，不会自动替换基线。

更新时先生成、审阅并公开候选报告，再单独执行基线更新脚本。
详见[质量控制文档](../docs/quality.md)。
