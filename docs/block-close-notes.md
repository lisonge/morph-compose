# Block / Close 手写动画的启发

示例移植自 GKD 的 `gkd-app/src/main/kotlin/li/gkd/app/ui/icon/GkBlockCloseIcon.kt`，
位于 Playground → Custom icons → Block / Close。
保留最新原文件的 ImageVector 几何、300ms tween 和单一进度；两条直线使用平头端点，
圆弧独立成路径并保留圆头，避免 Close 带有原版没有的圆角。将 GKD 的 Material3 按钮外壳
换成项目现有 Material Icon，由示例卡片处理点击。没有修改通用变形算法。

## 它实际做了什么

令 p=0 表示关闭，p=1 表示禁止。24×24 视口中，圆心为 (12,12)，半径为 9，线宽为 2。

- 公共 `/` 斜线保持中心和方向，半长度从圆半径投影的 90% 增长到 100%，并非完全静止。
- `\` 斜线以 `max(1-p/0.55, 0)` 缩向中心，在几何进度 55% 时消失。
- 两段圆弧分别从 -45° 和 135° 出发，各自扫过 `180° × p`，最终拼成圆环。
- 圆弧和斜线收缩从一开始同时发生，并非先收缩再画圆。55% 是缓动后的几何进度，
  不是 300ms 的 55%。反向切换仍沿同一参数曲线行进。

## 对项目的价值

1. **保留公共结构，减少无意义运动。** 项目已有 SharedBoundary 和描边中心线表示，
   但公共区域约束不等于笔画身份。这个案例提示对应阶段可以探索稳定主笔画与附属笔画的关系，
   同时允许公共笔画端点做小幅延伸；不能简单要求整条笔画逐点固定。
2. **“生长”应成为显式运动选项。** 当前 `Interpolate.kt` 主要插值配对采样点；
   沿固定圆周延长可见弧段，与把一条线的点移动成圆完全不同。可先探索显式的路径裁剪/弧长揭示、
   消失锚点和局部时间区间，再考虑根据几何关系自动提出候选。
3. **端点无法唯一决定好看的过程。** 同一组端点可以旋转、收缩、画出或重排笔画。
   这里的两个圆弧起点和 0.55 阈值都是作者选择。适合为有设计要求的调用者提供可选运动提示，
   而不是把这组参数推广为 Auto 规则。任何自动选择都应基于几何性质，禁止按图标名称分支。
4. **中断应共享一条连续状态轨迹。** 几何只依赖 p，切换目标不会立刻切换几何公式。
   对固定图标对很直接；项目支持任意目标，仍需要现有快照规划，单一 p 不能替代它。
   tween 也不保证反转时速度连续。

## 不能直接照搬的细节

- 最新原实现与本示例均对直线使用平头，`remaining == 0` 时收缩直线被删除。
  圆弧仍使用圆头，出生时附近不一定完全被短了 10% 的公共斜线遮住。
  因此不能仅凭坐标连续就宣称像素连续；若推广策略，需要专门检查出生、消失和拼接时刻。
- 每个进度值都会重新构造 ImageVector；`remember(progress)` 只复用相同进度，
  不会消除逐帧分配。它适合作为保真参考，大规模使用前可评估直接绘制 Path 和对象复用，需实测收益。
- 这套端点仍是手写描边，移除圆头并不保证尺寸与 Material 原版填充图标完全一致。比较通用算法时，
  应使用相同端点、线宽与渲染尺寸，避免将输入差异误认成算法优势。

建议先把它当作运动设计参考。若后续扩展库，优先做显式路径揭示与锚点提示原型，
并补充旋转/缩放无关、近端点像素连续、出生消失与多次中断性质测试；
按 `quality.md` 执行验证后，再评估是否具备自动策略的适用条件。
